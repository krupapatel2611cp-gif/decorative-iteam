# ✦ DecorAura — Decorative Items Blog

A frontend Web Application Development project made with HTML5, CSS3 and JavaScript.

## Features
- Decorative items: wall art, mirrors, lamps, plants, candles, cushions, vases and more
- Search and category filtering
- Room decoration ideas
- Curated collections
- Blog/articles
- Wishlist using browser localStorage
- Login and registration frontend validation
- Responsive design
- Online images
- GitHub Pages compatible
- No backend/database required

## Run
Open `index.html` in a browser or use VS Code Live Server.

## GitHub Pages
Upload the complete project to GitHub, then enable Settings → Pages.

## Technologies
HTML5 • CSS3 • JavaScript • localStorage

## Academic note
This is a frontend-only demonstration. Account and wishlist information is stored locally in the browser.
